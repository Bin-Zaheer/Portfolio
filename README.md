# BIN ZAHEER

Premium one-page agency website built with Next.js, TypeScript, Tailwind-ready project structure, Framer Motion and Lucide React.

## Install

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main files

- `app/page.tsx` — one-page section order
- `app/globals.css` — complete styling and responsive design
- `components/Header.tsx`
- `components/Hero.tsx`
- `components/About.tsx`
- `components/Services.tsx`
- `components/Projects.tsx`
- `components/Team.tsx`
- `components/TechCarousel.tsx`
- `components/Contact.tsx`
- `components/Footer.tsx`

## Replace later

Project and team images are remote demo images. Replace the URLs inside `Projects.tsx` and `Team.tsx` with your own images.

The contact form currently opens the visitor's email client using `mailto:`. For real website submissions, connect it later to Formspree, Resend, a Next.js API route, or another form backend.
